# Sawa 🤝🌍

🌐 Live Website: http://sawa-together.com/

## 📖 Overview
Sawa is a humanitarian coordination platform dedicated to organizing community support and managing resources efficiently. By providing a centralized digital hub, the platform connects individuals in need with available aid, streamlining the process of requesting, tracking, and distributing resources. Designed with a mobile-first, highly responsive interface, Sawa ensures that volunteers, organizers, and community members can easily access the platform from any device, making coordination fast and accessible during critical moments. ❤️

## ✨ Key Features
* 🤝 Community Coordination: Streamlined tools for organizing and distributing humanitarian aid and resources.
* 📱 Mobile-First Design: A highly responsive layout built to look great and function perfectly on any device.
* 🎨 Modern UI/UX: Clean aesthetics featuring glassmorphism effects, consistent styling, and an intuitive user experience.
* 🗄️ Resource Management: Efficient database tracking to monitor available community needs and support.

## 💻 Tech Stack
Frontend:
* 📄 HTML5
* 🎨 CSS3 (Mobile-first, Flexbox, precise rem & fixed pixel sizing)
* ⚡ JavaScript

Backend & Database:
* 🐘 PHP
* 🗄️ SQL
